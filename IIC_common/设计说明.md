# 通用IIC模块的设计

## 设计说明

在当前的编码器项目中，我们涉及了多种 IIC 接口设备，例如 ADS1110 ADC 和 AT24C128C EEPROM 等。然而，现有项目中的 IIC 通信模块大多是针对某一特定器件定制实现的，时序逻辑紧耦合于具体芯片，导致模块的可复用性较差。当 IIC 总线上挂载多个从设备时，这些为单个设备量身打造的驱动无法高效、统一地管理与总线上所有从机之间的通信。为解决这一通用性问题，我设计了本模块。

<br>

## 设计目标

该模块应支持对所有的 IIC 设备的通信时序，应实现如下功能：

1. 用户可以根据需要，选择合适的 IIC 通信命令，包括：

   | 命令                 | 编码   | 功能         |
   | -------------------- | ------ | ------------ |
   | USERCMD_NOTHING      | 3'b000 | 没有任何操作 |
   | USERCMD_READ_SINGLE  | 3'b001 | 读取单个数据 |
   | USERCMD_READ_BULK    | 3'b010 | 读取多个数据 |
   | USERCMD_WRITE_SINGLE | 3'b011 | 写入单个数据 |
   | USERCMD_WRITE_BULK   | 3'b100 | 写入多个数据 |

2. 支持对 10 bit 、7 bit 的 IIC 设备的从机地址进行自判断
3. 支持对 16 bit 、8 bit 、0 bit 的 IIC 从机寄存器地址进行自判断

<br>

## 逻辑实现（抽象层说明）

### 用户逻辑接口层

IIC_common模块完成的就是这一抽象层。

负责向用户提供 IIC 通信接口，用户逻辑仅需负责进行如下的任务：

1. 用户命令
2. IIC设备地址（7位或10位地址都可以）
3. IIC设备的寄存器地址（如果有的话）
4. 控制写入数据的输入以及读出数据的存储 （对于多字节连续收发，本模块会在1byte收发结束后发出一个rw_byte_ready脉冲）
5. 读写信号的字节数
6. 命令开始执行信号（一个脉冲）

除此以外，该模块还提供如下信号：

1. IIC忙标志：通信时为1，空闲时为0
2. 错误标准，只要发生错误就一直为1，直到模块复位

### IIC通信层

该抽象层由IIC_common的状态机进行完成。

负责如下任务：

1. 处理与之通信的IIC从机的不同的IIC地址与寄存器地址的情况

2. IIC 通信时的逻辑控制

经研究发现，无论IIC从机的IIC地址与寄存器地址的情况如何，对于IIC主机的发送来说只有如下的基础动作：

1. 空闲态
2. 发送起始位
3. 发送停止位
4. 发送 1 byte 数据
5. 接受 1 byte 数据
6. 发送应答
7. 接受应答

故结合用户逻辑接口层的需要，将状态机的状态定义如下：

| 状态                 | 编码               | 描述                 |
| -------------------- | ------------------ | -------------------- |
| STATE_IDLE           | 12'b0000_0000_0001 | 空闲状态             |
| STATE_PARSE_CMD_ADDR | 12'b0000_0000_0010 | 解析命令和地址状态   |
| STATE_IIC_START      | 12'b0000_0000_0100 | 发送起始条件状态     |
| STATE_SDND_BYTE      | 12'b0000_0000_1000 | IIC写数据状态        |
| STATE_SLAVE_ACK      | 12'b0001_0001_0000 | 等待从设备应答状态   |
| STATE_IIC_RESTART    | 12'b0000_0010_0000 | 发送重复起始条件状态 |
| STATE_REV_BYTE       | 12'b0000_0100_0000 | IIC读数据状态        |
| STATE_MASTER_ACK     | 12'b0000_1000_0000 | 发送主设备应答状态   |
| STATE_IIC_STOP       | 12'b0001_0000_0000 | 发送停止条件状态     |
| STATE_ERR_STOP       | 12'b0010_0000_0000 | 错误停止状态         |

<br>



### IIC 原子动作层

这个抽象层由IIC_atom模块实现，在IIC_common模块中进行例化。

负责完成IIC通信层的基础动作：

| 原子操作           | 编码      | 描述         |
| ------------------ | --------- | ------------ |
| IIC_ATOM_NONE      | 6'b000000 | 无操作       |
| IIC_ATOM_START     | 6'b000001 | 发送起始条件 |
| IIC_ATOM_END       | 6'b000010 | 发送停止条件 |
| IIC_ATOM_SEND_BYTE | 6'b000100 | 发送字节     |
| IIC_ATOM_RECV_BYTE | 6'b001000 | 接收字节     |
| IIC_ATOM_SEND_ACK  | 6'b010000 | 发送应答     |
| IIC_ATOM_RECV_ACK  | 6'b100000 | 接收应答     |
